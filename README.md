# Clean manga extension list

A guarded copy of the Keiyoushi extension list for Tachimanga (and Mihon).
This repository only holds the published list and the extension files.
It is updated automatically.

## Add it to Tachimanga

Browse → Extensions → settings → Extension repos, then add:

```
https://github.com/foku1-create/clean-manga-repo/raw/main/index.pb
```
